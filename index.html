WHY THESE DATA STRUCTURES?

Two queues. Two jobs.

Each structure has a real responsibility in the delivery workflow, which makes the project easy to explain in a DSA viva.

Circular Queue

Regular orders are added at the rear and dispatched from the front. Empty array positions are reused through wrap-around.

rear = (rear + 1) % capacity

PROJECT ABSTRACT — WEB DEMO

Smart Food Delivery Dispatch System

DashFlow demonstrates how delivery platforms can separate normal order processing from priority handling using two queue structures. Regular orders follow FIFO behavior through a Circular Queue.

The Deque gives extra flexibility for urgent, reassigned, or special orders. The browser simulation visualizes each operation so the same logic can be recreated in Java.
