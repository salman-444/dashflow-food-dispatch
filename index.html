    THE LOGIC BEHIND THE DELIVERY
    ↻01 / REGULAR LANEO(1)

    Circular Queue

    Regular orders follow FIFO: the first order in is the first order out. A fixed array holds 8 orders. When an order leaves, its slot becomes available for reuse.

    // The rear wraps; the array stays put.rear = (rear + 1) % capacity

    Front points to the next order to leave. Rear points to the last order added. A count distinguishes a full queue from an empty one.

    enqueue()dequeue()frontrearisFull()isEmpty()
    ⇄02 / PRIORITY LANEO(1)

    Deque

    Some orders need a faster route. Urgent, delayed or reassigned orders enter at the front. Special orders with lower priority join at the rear.

    // Every dispatch checks this lane first.!deque.isEmpty() ? deque : queue

    Insert or remove at either end. This implementation also uses a fixed circular array, so all four operations take constant time.

    addFront()addRear()removeFront()removeRear()
